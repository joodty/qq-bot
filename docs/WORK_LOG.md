## 2026-10-21—22：当前业务功能的形成

### 按对象人设、会话恢复与费用

需求从“各群分别选人设”扩展到群聊、私聊和管理员私聊的统一覆盖；未设置沿用全局。原系统已隔离聊天对象上下文，扩展没有把所有群合成一个会话。增加会话档案以支持 A → B → A 恢复原后端会话；增加按天与对象的用量、估算费用统计。

### 多账号、多机器人与 SQLite

SQLite 保存管理状态并保留已有账号、角色、Cookie 和后端会话标识；独立运行实例按机器人归属隔离。普通账号可在本人/委托范围内编辑和切换人设，保存本人 Key 并选择费用来源。平台体验与自费路径分开，失效 Key 不静默回退平台资金。

群与私聊通常默认每日 ¥1；约 80% 时降低输出和参与，限额后停止新付费调用。平台体验默认个人每日 ¥0.10、平台共享每日 ¥1。既有显式平台资助有兼容边界，具体行为以预算/租户模块为准。

### 最新已发布的账号与公共说明改动

网页移除令牌登录，开放固定普通角色的自助注册，注册自动登录并保留 Cookie。用户机器人接入改为不含机器凭据的申请：平台准备独立实例、本人扫码、管理员验证后启用。补充异步账号撤销、费用变化、归属转移和补偿保护。新增匿名数据模型页，当前实际结构与拟议模型明确分开。

上线时只更新目标机器人应用；原管理员账号、两个既有登录会话、四个活动群会话及角色保持不变，模型后端和 QQ 就绪，其他服务/代理进程未变化。公网匿名页面、结构哈希和未登录私有 API 拒绝均已只读核验。这是当时结果，不替代未来线上检查。
