# 项目交接：从这里继续

更新日期：2026-10-22。公开仓库：[joodty/qq-bot](https://github.com/joodty/qq-bot)，默认分支 `main`。本文件不包含服务器连接或 API 私密信息。

## 这是什么项目

基于 [Derpyu520/qq-bridge](https://github.com/Derpyu520/qq-bridge) 的 QQ AI 机器人管理扩展，保留 MIT 许可与原作者署名。基础链路是 QQ → SnowLuma / OneBot → Bridge → DeepSeek Harness（DSH）；另有用户自带 Key 的独立聊天路径。此公开仓库不是对上游完整 Git 历史的镜像：最初来自既有运行源码快照，首次公开使用经过脱敏的当前源码起点，原始快照留在本机，不随公开分支上传。

最初需求是让不同群的人设互不冲突，随后扩展到私聊、人设会话切换、费用额度、多机器人和多账号。详细调整理由见 [设计决策](DESIGN_DECISIONS.md)，不要从早期讨论中的猜测推断现状。

## 当前已经实现

| 业务 | 当前行为 |
| --- | --- |
| 人设 | 群聊、私聊、管理员私聊使用统一会话键；单独选人设，未设则继承全局。普通账号能在本人/委托范围内创建、编辑、切换人设 |
| 会话 | 不同群/私聊原本就有独立上下文。会话档案记录聊天对象、人设及后端标识，切回旧人设可继续其原会话；不保证供应商缓存永久命中 |
| 存储 | 管理状态采用 SQLite，当前结构版本 1、26 张表。部分业务文档存在 `state_documents`；用量 JSONL、活动映射及 DSH 消息存储仍有明确边界 |
| 账号 | 保留唯一平台管理员；公开注册固定普通账号、空授权，注册后自动登录。网页使用 HttpOnly Cookie，通常保留 30 天，密码最短 10 字符 |
| 权限 | 管理员管理平台默认项。普通账号只管理本人 Key、验证绑定的私聊、所属机器人与明确委托的群/私聊；拥有 Key 或机器人不会变成平台管理员 |
| 费用 | 群与私聊通常默认每日 ¥1，可配置；约 80% 时减少参与/输出，100% 时拒绝新的付费调用，按北京时间次日恢复。费用是估算与在途预留，不是供应商账单 |
| 体验 | 本人 QQ 经真实事件验证后可用平台试用，默认每人每日 ¥0.10、平台共享每日 ¥1；管理员可改，普通用户不能抬高平台补贴 |
| 自带 Key | 当前仅 DeepSeek 官方接口及代码白名单模型。Key 加密保存；失效或删除后停止使用，不自动回退花平台的钱 |
| 多机器人 | 一个管理入口代理多个独立运行实例。平台安装登录服务后，用户提交本人配置和机器人 QQ，自动准备独立环境、网页扫码、后台核验并启用；支持关闭继续和重新连接。未启用自助服务时保留人工准备流程 |
| 普通账号页面 | 按主页、聊天与人设、费用与额度、我的机器人、账号设置、使用帮助组织；手机底部四项导航。主页引导绑定 QQ、开始聊天、选择人设，API 为可选步骤 |
| 说明页 | `/permissions` 先给操作帮助，权限细节可展开；`/data-model` 匿名展示实际 ER、字段字典和目标模型讨论。目标图中的新对象尚未代表数据库已迁移 |

## 已知边界与接下来可优化的部分

- 独立 QQ 支持网页扫码和按申请准备环境，先由平台安装固定镜像、程序依赖和内部登录服务；注册网页账号不会直接登录 QQ。当前生产容量为一个额外机器人，扩大容量需评估实际资源；本人扫码后的真实身份须另行确认，见 [网页 QQ 登录](guides/WEB_QQ_LOGIN.md)。
- 尚未把所有数据统一为 Conversation / ChatSession / UsageRecord 关系模型；不要根据目标 ER 图直接认为这些表存在。
- 普通账号的任务导航和手机入口已整合，细节见 [页面说明](guides/MEMBER_NAVIGATION.md)；机器人完整控制台仍是该实例的详细管理页面，平台管理保持独立范围。以后可继续精简完整控制台中的高级表单。
- 账号总量目前有上限，公开注册不等于已具备大型 SaaS 的租户规模与自助资源编排。
- 最近完整审计 61/63：`test-voice-system.mjs` 依赖未随公开源码提供的旧语音文档；`test-preset-local-tools.mjs` 需要本机 DSH 安装工具清单。它们没有被伪装成通过。`test:core` 是可在干净克隆中执行的独立检查集合，不替代完整审计。
- 本地浏览器夹具和公网只读核验都曾执行；新设备应重新运行，不把旧结果当成当前机器的验证。

线上连接、备份路径、凭据及个人运行数据不属于公共交接范围。没有这些资料也可以独立开发和提交代码；部署状态必须另行核验。
