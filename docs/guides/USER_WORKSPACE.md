# 我的空间、费用来源与机器人权限

普通用户可在 `/login` 自行注册普通账号，密码至少十个字符，注册后直接进入 `/workspace` 的“我的主页”，按绑定 QQ、去 QQ 聊天、选择人设的顺序开始。费用、可选 API 密钥、机器人、账号分别进入；手机底部提供主页、聊天、费用、机器人四项入口，详见 [页面入口说明](MEMBER_NAVIGATION.md)。网页登录只使用账号密码与浏览器登录 Cookie，不接受访问令牌。平台管理员继续从 `/` 管理平台，也能进入自己的主页。`/permissions` 先提供操作帮助，权限说明可展开；`/viewer` 先选具体群或私聊，再设置人设。平台尚未初始化或注册关闭时，页面会明确提示，不提供创建管理员的网页入口。

## 三种空间状态

| 状态 | 机器人与费用来源 | 可以管理的资源 |
| --- | --- | --- |
| 体验 | 共享平台机器人，平台提供有限体验费用 | 经过真实 QQ 一次码验证的本人私聊、人设与本人费用概况 |
| 自带 Key | 共享平台机器人，明确选择自己的模型配置 | 本人的私聊、自有模型配置与自费每日额度 |
| 托管 | 独立 QQ 机器人与自己的模型配置 | 所属机器人的群、私聊、人设、会话、费用、准入和具体成员授权 |

普通用户拥有机器人后仍是平台普通账号。机器人所属关系只授予该机器人的管理能力，不授予平台账号、服务器运维、DSH、本地工具预设或其他机器人的权限。API Key 只决定费用来源。

## 开通自己的私聊

1. 在空间填写自己的 QQ，申请十分钟有效的一次码。
2. 使用那个 QQ 私聊平台机器人，发送网页显示的 `/bind 一次码`。
3. 返回空间点击“我已发送，检查绑定”。填 QQ 号本身不授予权限。
4. 可以使用平台体验，或者保存自己的模型配置后明确选择私聊费用来源。

体验默认每个已验证私聊每日 ¥0.10，平台管理员设置默认体验额度和平台体验总日预算。原有 `ownerQQ` 或 `allow.private` 中由管理员明确配置的平台资助对象保留既有费用策略；绑定并不自动撤销原资助。显式选择费用来源后按所选来源执行。

自费默认每日 ¥1，可以自行调整本人额度。费用按估算支出与在途预留控制新的模型调用；80% 后减少输出与参与，100% 暂停，次日恢复。实际供应商账单与估算可能存在差异。费用账本不能清空以恢复当日额度。

## 密钥与配置

只支持 DeepSeek 官方接口以及 `deepseek-flash`、`deepseek-v4-pro`。不接收自定义请求地址。模型配置保存后只显示名称、模型、版本和可用状态，不返回 Key、密文或 Key 后缀。成功保存会清空网页密钥输入框；修改时留空保留原 Key。

保存配置不自动切换费用来源。失效 Key、余额不足、请求失败、删除正在使用的模型配置都会停止对应自费调用，不会自动改用平台 Key。需要在空间修复配置或本人明确切换来源。

## 托管与成员授权

用户先验证本人 QQ，在“我的机器人”填写机器人 QQ、名称并选择自己的有效模型配置。平台启用网页接入后，提交会弹出扫码窗口并自动准备独立环境；本人手机确认后，后台核验 QQ 与费用配置并启用。已接入实例可查看连接或重新扫码。未启用网页接入时仍由平台准备、本人扫码和管理员核验。普通账号不用填写服务器连接信息；注册或填写 QQ 号不会直接认领已有实例。见 [自有机器人开通申请](BOT_ONBOARDING.md) 和 [网页 QQ 登录](WEB_QQ_LOGIN.md)。

“我的机器人”只列出本人所属机器人。点击“管理这台机器人”进入其控制台。分享聊天时输入完整的现有账号名和每行一个群号，需要分享私聊时展开额外列表填写 QQ 号；程序转换为 `group:群号` / `private:QQ号`，后端仍必须同时匹配机器人和会话类型/号码。两个列表都留空撤销该成员的会话授权。被授权成员通过 `/viewer` 管理自己的人设卡与授权对象，不会获得机器人所有者或平台账号管理能力。

## 本地验证

- `scripts/test-workspace-ui.mjs`：隔离 HTTP/浏览器界面、密钥清空、QQ 待验证、自费选择、CAS、托管、成员授权、权限图、手机与暗色布局。
- `scripts/test-registration-ui.mjs`：真实注册、空普通权限、密码确认、持久 Cookie、重名冲突、注册关闭、拒绝旧网页登录令牌与管理员密码登录。
- `scripts/test-workspace-real-ui.mjs`：真实 Bridge、账号、SQLite 和浏览器，包括实际命令处理器中的模拟 QQ 绑定与账号隔离。
- `scripts/test-tenant-bridge.mjs`：真实管理器和两个 Bridge 工作实例，模拟官方模型响应与 QQ 传输，覆盖自费回复、费用归属、密钥失效无平台兜底、所有权及精确会话授权。
- `scripts/test-slang-budget-ui.mjs`：手动黑话研究的三条入口均必须携带所选会话费用归属，预算拒绝不会改投其他对象。

上述测试只使用临时数据库、模拟 QQ 和模型响应，不读取生产凭据或产生真实付费请求。
