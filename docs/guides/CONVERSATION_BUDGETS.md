# 每个会话的每日额度

管理员打开“令牌与花费 → 会话每日额度”，可以设置当前机器人的默认每日额度，以及单独群、普通私聊、管理员私聊的覆盖额度。每个对象分别计算，默认每天人民币1元。多机器人的额度互不混用；切换顶部机器人后，页面会查询所选机器人的额度。

单个对象留空表示沿用默认额度，0表示不分配新的模型调用额度。修改后点击“保存预算设置”；未保存草稿不会被自动轮询覆盖。其他窗口修改了配置时，旧版本保存会被拒绝，草稿保留；点击“刷新预算”并确认后，才放弃草稿并读取最新设置。

被授权成员可查看具体授权对象的额度状态。普通账号选择自己的有效 API Key 后，可以调整本人私聊的自费额度；机器人所有者可调整自己机器人的群与私聊额度。平台体验补贴额度仍只能由平台管理员修改，各账号不会获取其他对象的预算信息。

## 状态与金额含义

- **正常**：按原来的规则处理新调用。
- **节流**：估算费用与在途预留达到今日额度的80%，开始减少输出和参与；群和私聊都适用。
- **暂停新的模型调用**：估算费用与预留达到额度，新调用被拒绝；北京时间次日重新计算每日额度。
- **额度限制未启用**：管理员停用了相应限制。
- **计价不支持**：无法可靠获得人民币估算时，不把未知费用当作0放行，页面显示暂停状态。

“已估算支出”来自费用账本；“在途预留”是对尚未完成调用保留的额度；“剩余额度”同时考虑两者。暂停只限制新的模型调用，已经运行的请求仍可能产生费用。金额按当前配置价目表估算，不包含未上报或无法计入的支出，不能承诺供应商实际扣款绝对不超过1元。

主入口为 `GET/POST /api/conversation-budgets`；旧 `/api/group-budgets` 仅作兼容命名，私聊同样支持。配置中保留的 `groups` 字段是兼容结构，键可以是 `group:群号` 或 `private:QQ号`。写入带当前 `configVersion`；覆盖值为对象，`null`表示删除覆盖。成员概况通过每行 `budget` 返回只读状态，不开放额度管理接口。

桥接在发起付费请求前预留额度，回合结束后结算。达到80%后停止自主冒泡和后台学习，明确私聊或点名请求限频，回复收为一条、最多120字。自带 Key 的文本引擎另将 `max_tokens` 降至256；原 DSH 接口不支持硬输出参数，只能通过提示和实际发送限制收短，不能保证供应商生成量与最后显示字数相同。

启用 SQLite 预算的实例，独立联网搜索使用免费 Bing RSS/网页后端，避免没有会话归属的额外 DeepSeek 搜索请求绕过预算。费用账本参与限额，禁止清空；按日期筛选不会改写记录。账本读写故障会阻止新的付费调用，并保留故障标记供修复。

`scripts/test-conversation-budget-ui.mjs` 使用本机隔离HTTP与模拟账本，验证群/私聊/管理员私聊显示、覆盖与继承、版本冲突、失败恢复、多机器人隔离、成员只读权限、移动和深色布局。测试不发送真实消息或调用付费模型。
