# 每日会话费用统计

控制台的「令牌与花费 → 每天花到哪里」按北京时间自然日（UTC+8）展示保留的模型调用明细。默认最近七个日历日，可查询最多 90 天；可选择所有会话或一个群聊、普通私聊、管理员私聊、内部任务。会话换了 DSH session 后，只要保留原 QQ 会话 key，就继续汇总到同一行。

页面提供所选日期的费用合计、会话费用排行、每天 × 会话明细、每日合计，以及未命中输入/缓存写入、缓存命中、输出的分项费用。每日合计保留无记录的日期；无记录表示没有保留的调用，不能证明供应商没有扣费。

## 金额与历史覆盖口径

- **日报金额**：保留的 provider usage 采样，按每次调用记录的时间和模型，使用当前配置价目表折算。流式结算覆盖同一步骤，重放不重复计数，重试另算一次调用。
- **累计快照估算**：原有累计 token 投影仍保留。整个历史基线按快照时刻估价，历史横跨计价时段时，它可能与逐次定价的日报金额不同。该累计金额没有改成另一种口径。
- **缺日期历史**：基线或已压缩淘汰的历史只有累计 token，不能可靠分摊到某天。页面单列缺少可定位日期的 token，绝不把快照接收日当消费日。新摄入但没有事件时间的采样标记 `timeEstimated`，日报排除它并提示缺日期；旧版已把接收时间写为普通时间戳的记录，无法事后恢复真正发生时间。
- **模型未知**：按现有配置兜底价估算，页面显示本期有多少次调用使用兜底价。
- **并非供应商账单**：不包含 Search / Fetch 等工具按请求计费、未上报用量、账号优惠/赠送余额扣减，以及通过其他客户端产生的支出。只有供应商账单能确认账户实际扣款。

2026-10-21 已核对 [DeepSeek 官方价目表](https://api-docs.deepseek.com/zh-cn/quick_start/pricing/)：Flash 空闲单价为缓存命中 0.02、未命中 1、输出 4 元/百万 token；Pro 为 0.15、4.5、13.5，高峰倍率为 2，与此版本内置数值一致，因此未调整价格。官方同时列出 Search/Fetch 独立计费；此日报只统计 token。内置版本字符串 `2026-11-04` 是已有配置标记，不代表本次核验日期，也不能作为实时价格保证。`pricing` 配置覆盖项仍生效，历史金额也会按当前配置重算；既有节假日表含未来推定安排，不能视为未来官方日历保证。

## 接口和数据兼容

只读 `GET /api/tokens/daily?from=YYYY-MM-DD&to=YYYY-MM-DD&key=group%3A123`。省略日期默认最近七天，省略 `key` 返回所有会话。日期无效、倒序或超过 90 天返回 400。必须通过控制台鉴权，群内 agent token 无权读取跨群费用。

返回 `totals`、`days`、`rows`、`conversations`、`availableKeys` 与 `coverage`；分项 `costs` 包括 `cacheMiss/cacheHit/cacheWrite/output`。`coverage.unallocatedTokens` 是累计投影/淘汰历史中缺明细部分，`undatedTokens` 是已保留但缺可靠时间的采样；两项均不归入日报金额。覆盖提示属于所选会话的全部历史，日报合计仅属于所选日期。

使用原有 `state/token-usage.jsonl`，无迁移和新运行时依赖；读取旧行时缺省字段按旧格式处理。新增可选字段 `timeEstimated: true` 不改变旧版累计统计。查询不写账本、不重建会话、不发送消息、不调用付费模型、不改价格或代理配置。压缩上限仍沿用原有设置，较早明细可能只剩累计 token，无法承诺任意历史日期均有完整记录。

## 验证

使用项目要求的 Node 22.13+：

```text
node scripts/test-token-daily.mjs
node scripts/test-token-usage.mjs
node scripts/test-token-daily-ui.mjs
```

浏览器脚本需要 Playwright（可用 `PLAYWRIGHT_MODULE` 指向本机已安装目录）及 Chrome/Chromium。后端共 15 个用例，浏览器共 10 个用例，覆盖午夜边界、峰谷分项、基线与压缩、重连幂等、退休会话、私聊/管理员/内部归属、未知模型、日期验证、控制台鉴权、错误恢复、HTML 转义与移动/深色布局。集成测试启动隔离真实 bridge 路由，所有模型、QQ 连接和数据均为模拟；未发送真实 QQ 消息或请求付费模型。
