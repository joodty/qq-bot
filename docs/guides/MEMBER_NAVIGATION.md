# 普通账号的页面入口与手机使用

页面按用户要完成的事组织。平台角色仍然只有管理员和普通账号，菜单不会切换账号身份或扩大资源权限。

## 入口结构

```text
我的主页 /workspace#home
  └─ 绑定自己的 QQ /workspace#start
聊天与人设 /viewer
  └─ 选择机器人 → 选择群聊或私聊 → 编辑、保存、应用人设
费用与额度 /workspace#billing
  └─ 我的 API 密钥 /workspace#models（可选）
我的机器人 /workspace#bots
  ├─ 接入申请 → 网页扫码 → QQ 核验 → 开通进度
  ├─ 管理所属机器人 /?bot=所选实例
  └─ 分享指定群聊或私聊给其他账号
账号设置 /workspace#account
  └─ QQ 绑定状态、修改密码
使用帮助 /permissions
  ├─ 按操作找入口
  ├─ 展开的权限说明（可选阅读）
  └─ 公开的数据模型说明 /data-model
```

管理员另有平台管理入口；普通账号不会因此看到平台额度表单或获得平台接口权限。机器人的完整控制台保持独立，用于该机器人下的准入、会话、费用等详细管理。

## 第一次使用

注册后主页先给出一件下一步要做的事。未绑定 QQ 时进入验证步骤；发送真实 QQ 私聊验证指令后回网页检查。绑定成功且费用来源可用时，显示机器人 QQ 和本人私聊人设的入口。平台体验关闭、额度用尽或自费配置失效时，主页分别说明阻碍和处理入口，不错误提示已经可以聊天。

自己的 API 配置和机器人接入是可选步骤，首次使用不需要先理解或填写它们。保存 API 配置仍须明确选择付费方式才会用于私聊。接入表单先显示 QQ 绑定和自有 API 配置的准备状态与操作入口；无配置时显示明确提示，不能留下空白选择框。尚未接入的机器人显示申请与扫码进度，不能提前显示已获得管理权限。网页扫码支持关闭继续、过期刷新及已接入实例的重新连接，见 [网页 QQ 登录](WEB_QQ_LOGIN.md)。

## 人设与聊天对象

先选机器人和群/私聊，再编辑角色卡；页面直接显示当前聊天和正在使用的人设。保存角色卡与应用到聊天保持两个明确动作。没有可管理对象时，显示绑定 QQ 与获取群聊分享的指引。费用明细放在可展开区域，避免挤占主要编辑流程。

主页可通过 `/viewer?bot=实例&key=private%3A号码` 定位本人私聊。URL 中的聊天键必须实际出现在后端返回的授权列表中才能选中；它不创建授权，不会自动应用人设。

机器人所有者分享群聊时只填账号名和每行一个群号；需要分享私聊时展开额外列表填写 QQ 号。前端转换为既有的 `group:` / `private:` 请求格式，后端仍严格校验机器人归属、精确对象和版本。两个列表都为空表示撤销分享。

## 手机端

宽度不超过 760 像素时，底部固定四个入口：主页、聊天、费用、机器人；顶部保留账号设置与使用帮助。电脑端是六项侧栏，页面路径和权限相同。选中项随页面切换更新。

表单采用单列，主要按钮与输入控件最小高度 44 像素，输入字号 16 像素；底部预留导航与设备安全区。文本输入获得焦点时收起底部导航，避免占用编辑空间。长费用表保留局部横向滚动，页面本身不能被撑宽。浅色和深色均支持。

自动测试覆盖 320、390、768 像素视口，检查导航、触控尺寸、输入焦点和页面溢出；这不等同于真实 iPhone/Android 键盘验证。机器人完整控制台沿用原有响应式布局，本轮重点是普通账号的开始使用与日常操作。

## 文案与兼容

| 旧表达或组织 | 当前表达或组织 |
| --- | --- |
| 已授权会话人设 | 聊天与人设，先选择具体聊天 |
| 空间与权限图 | 使用帮助，先提供操作入口 |
| 选择一个视角，查看权限 | 可选展开“了解账号与权限”，说明不同使用方式 |
| 首屏并排三种模式和所有配置表单 | 一个下一步，API、费用、机器人分别进入 |
| 成员填写 `group:号码` | 直接填写群号，程序处理请求格式 |

本轮仅修改 HTML/CSS/浏览器交互和测试，没有新增数据库表或修改后端接口。页面内切换子项不提交表单；已有草稿保持在当前页面，整页离开仍遵循原有行为。Cookie 登录、CAS、会话标识、费用策略和权限校验继续沿用原实现。

- `npm run test:member-navigation:ui`：真实隔离 Bridge + SQLite + Chrome，覆盖注册后指引、模拟 QQ 绑定、精确对象应用、API 显式付费、无授权 URL、防越权、帮助页、手机导航和修改密码。
- `npm run test:workspace:ui`、`npm run test:members:ui`：既有保存、冲突、隔离与人设操作回归。
- `scripts/test-account-ui.mjs`、`scripts/test-registration-ui.mjs`、`scripts/test-console-ui.mjs`、`scripts/test-owner-console-real-ui.mjs`：账号与完整控制台回归。
