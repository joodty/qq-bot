你想做什么？

私聊、换人设、看花费，按下面的入口操作。

我想和 AI 私聊

先绑定自己的 QQ，再用 QQ 给平台机器人发消息。可以先用平台体验，不必填写 API 密钥。

去绑定 QQ →

我想换个人设

进入聊天与人设，先选机器人和聊天对象，再选择或新建人设，最后点击应用。

去设置聊天人设 →

我想看花费、改额度

个人私聊费用在费用与额度。自己的群聊费用在对应机器人里查看。平台体验额度由平台设置。

查看我的费用 →

我想用自己的 API 密钥

先添加 DeepSeek API 密钥，再到费用概况选择由它支付。密钥失效会停止自费聊天，不会自动使用平台的钱。

添加自己的 API 密钥 →

我想让 AI 进自己的群

申请接入自己的 QQ 机器人。平台准备服务后，由你完成 QQ 扫码，核验通过才能管理它的群聊。

接入自己的机器人 →

为什么看不到某个群？

你只能管理自己的聊天，或机器人所有者明确分享给你的群。可以请所有者在他的机器人下添加你的账号。

查看我能管理的聊天 →
进一步了解：账号和管理范围

账号只有平台管理员和普通账号两类。下面的按钮只用于阅读说明，不会切换你的身份或付费方式。

不同使用方式能做什么

平台管理权限与资源所属关系分开判断；拥有一个机器人，不代表拥有整个平台。
01 / 体验

平台机器人 · 平台 Key

验证自己的 QQ 后，与平台机器人私聊。

你的账号 → 已验证 QQ → 自己的私聊
默认每日 ¥0.10，由平台管理员调整。只能使用自己的体验空间，不能提高平台补贴额度。
02 / 自带 Key

平台机器人 · 自己的 Key

仍使用共享平台机器人，只处理自己的私聊。

你的账号 → 自己的私聊 → 自己的 Key
默认每日 ¥1，可自行调整自费额度。自己的 Key 不会解锁平台机器人的其他群或其他用户数据。
03 / 托管

自己的 QQ 机器人 · 自己的 Key

你凭机器人所属关系，成为该机器人的管理员。

你的账号 → 自有机器人 → 该机器人的群与私聊
可管理自己机器人的准入、成员授权、人设、会话和费用；其他人的机器人与平台设置仍不可访问。
体验账号

先用真实 QQ 私聊一次码完成绑定。平台提供有限体验费用，额度由平台管理员控制。

四条固定边界

QQ 绑定要本人验证

输入 QQ 号只会申请一次码。必须由那个 QQ 在真实私聊中把一次码发给平台机器人，网页不能直接认领。

Key 只决定费用来源

保存自己的 API Key 不会获得任何其他机器人、群聊、会话或账号的访问权限。Key 保存后不回显。

自费失败不使用平台兜底

Key 失效、余额不足或连接失败时，停止相应自费调用并提示处理；不会悄悄切换到平台 Key。

管理员分为两种范围

平台管理员管理平台；普通用户可管理自己的机器人。被授权成员只管理授予他的具体机器人和群或私聊。
